# Abhisek & Anmol — Wedding Invitation

A royal, animated wedding invitation for Abhisek Panda and Anmol Tripathy.

**View the invitation:** https://abhisekpanda0.github.io/wedding-invite/

## Updating the invitation

Replace `index.html` with the latest `Wedding_Invitation.html` (rename the copy to `index.html`) and commit it to `main`. GitHub Pages publishes from the root of `main`. The invitation keeps its artwork, fonts, scripts and music embedded and can also be downloaded for offline use.

Phone browsers may require the first tap to start music.
